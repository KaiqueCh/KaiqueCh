# 👨🏻‍💻 Kaique Chaves

**`Analista de Sistemas | TOTVS Protheus | ADVPL | SQL | Integrações`**

Me chamo **Kaique Chaves**, sou Analista de Sistemas e estudante de Sistemas de Informação, com experiência em análise, desenvolvimento, implantação e sustentação de sistemas corporativos.

Atuo principalmente com o ecossistema **TOTVS Protheus**, possuindo experiência com **ADVPL, TLPP, SQL Server, PostgreSQL, REST APIs e integrações entre sistemas**. Também trabalho com soluções voltadas para automação de processos, análise de dados e infraestrutura de TI.

Tenho experiência com o módulo **Posto Inteligente / KingPosto**, integrações com **TEF, PDVs móveis, PinPads, ACS** e outros sistemas utilizados no segmento de postos e varejo.

Além do ERP, desenvolvo soluções utilizando **Python, PHP e JavaScript**, realizo integrações através de APIs e utilizo **Power BI** para criação de indicadores, dashboards e análise de dados.

Busco constantemente evoluir tecnicamente, compreender os processos de negócio por trás das aplicações e desenvolver soluções que tragam eficiência, automação e confiabilidade para as operações.
